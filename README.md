Repositório criado para armazenar meus primeiros projetos desenvolvidos em Python.

## Projetos:

Calculadora: Calculadora simples capaz de realizar operações matemáticas básicas.
**Arquivo:** `calculadora.py`

Calculadora de Média: Programa que recebe notas e calcula a média do aluno.
**Arquivo:** `calculadora-media.py`

Conversor de Real para Dólar: Programa que realiza a conversão de valores de Real (BRL) para Dólar (USD).
**Arquivo:** `conversor-dólar-real.py`

## Tecnologias utilizadas:

- Python 3;
- VS Code;
- Git e GitHub.
